## Era-aware identifiers

NHTSA says vPIC is intended for model years 1981 onward, and excludes earlier nonstandard VINs. Its decoder reports manufacturer-submitted data; the ninth-position check digit belongs to the modern format. Preserve historical identifiers as bounded text and retain raw punctuation/format in evidence. Do not force 17 characters, forbid characters by modern rules, or compute a modern checksum for pre-1981/unknown-era identifiers. Modern validation should produce a review flag, not discard an advertisement. A successful decoder response supports what an identifier encodes, not the physical car's authenticity or originality. [NHTSA vPIC](https://vpic.nhtsa.dot.gov/); [NHTSA decoder](https://vpic.nhtsa.dot.gov/decoder); [NHTSA analytical user manual](https://crashstats.nhtsa.dot.gov/Api/Public/Publication/813348).

Modern US 1981+ 17-character syntax should exclude I/O/Q, with checksum only for applicable North American production identity; masked/partial/state-assigned/import identifiers stay reviewable. NHTSA's historical 1980 interpretation records exceptions for 1981-model vehicles manufactured before the transition date, another reason to avoid hard rejection based on claimed model year alone. [NHTSA 1980 transition interpretation](https://www.nhtsa.gov/interpretations/nht80-428); [NHTSA pedestrian coding manual with post-September-1980 syntax](https://static.nhtsa.gov/nhtsa/downloads/Ped/96PedMan.pdf).

## Routing provider: openrouteservice

Recommended supported adapter: hosted openrouteservice (ORS), `POST https://api.openrouteservice.org/v2/directions/driving-car/json`, API key in Authorization header. Coordinates are longitude/latitude. Use `options: {avoid_features: ['ferries'], avoid_borders: 'all'}` with origin/destination in US. Those options are documented for driving profiles. Parse returned summary distance and duration; keep seconds internally and compare `durationSeconds <= 14400` so rounding cannot admit a longer journey. Store provider/endpoint/options, coordinates, geocode precision and observation time in cache identity. [ORS routing options](https://giscience.github.io/openrouteservice/api-reference/endpoints/directions/routing-options); [request and return formats](https://giscience.github.io/openrouteservice/api-reference/endpoints/directions/requests-and-return-types).

Hosted ORS currently uses no live traffic; staff clarified in February 2026 that statistical traffic support is not available on its public API either. A city-center route should be labeled a nontraffic estimate from approximate endpoints. The map-data and route limitations remain even with avoidance options. Never label straight-line distance a four-hour route. Without a key or established vehicle coordinates, store duration/distance as null with reason, retain straight-line miles where available, and surface the listing in travel review. [ORS maintainer response, February 2026](https://ask.openrouteservice.org/t/isochrone-trafic-data/7875).

**Verified live plan limits:** Standard plan is €0; Directions V2 2,000/day and 40/minute; geocoding 3,000/day and 100/minute. Read through actual rendered account page because it is JavaScript-rendered. Registration and key creation are user setup; do not create accounts or accept terms automatically. Throttle below advertised caps, honor rate-limit responses and stop/back off on quota errors. Public directions maximum is 6,000 km and 50 waypoints. Hosted driving isochrones are capped at one hour, so do not promise a four-hour isochrone under the standard API. [Current HeiGIT plans](https://account.heigit.org/info/plans); [ORS endpoint restrictions](https://openrouteservice.org/restrictions/).

Terms observed on rendered page require ORS attribution and license ORS results under CC-BY-SA 4.0. Include `© openrouteservice by HeiGIT | Data from OpenStreetMap` with links. Terms limit accounts to one per person, prohibit overburdening services and prohibit transmitting personal data except account-management requirements. Send public city-center/dealer coordinates, not a private home street address or notes/identifiers. Terms do not promise accuracy or reproducibility. Keep provider result provenance/license separate when snapshotting. [Current terms and attribution](https://account.heigit.org/info/tos).

## Credential-free geocoding and maps

Public Nominatim is usable only for an informed, deliberately selected small application with prominent policy documentation. Rules observed: absolute maximum 1 request/second, identify application via a real User-Agent/Referer, attribute OpenStreetMap, cache results, one machine and one request thread for small one-time bulk work. Recurring scripts or ones running over a day are limited to 4 requests/minute. No autocomplete, systematic town/postcode enumeration, repeated identical queries, or confidential information. LLM-generated applications must explicitly explain restrictions; generic geocoding services created by vibe-coding platforms are disallowed. This is a specific single-user car-search use, but prefer an explicit bounded CLI with a conservative 15-second interval and persistent cache; keep automatic worker geocoding off. Make endpoint/provider switchable without application code changes. [Nominatim usage policy](https://operations.osmfoundation.org/policies/nominatim/).

For Wheaton, use an explicit query containing city + Illinois + United States, request structured address details with US country filter, and validate city/state/country before accepting the result. Save geocoder observation date, feature identity, bounding box/precision and query. Do not silently choose the first match when multiple results remain credible. Manual location correction should be a separate authoritative override. A route for an off-site car must wait until its actual vehicle location is established.

OSM standard tiles require visible attribution, HTTP caching headers (or at least seven days), a valid browser Referer, and no bulk/offline prefetching. Normal browser caching is appropriate. Avoid a restrictive Referrer-Policy that strips map tile Referer. Maps must fail independently from the list. [OSM tile policy](https://operations.osmfoundation.org/policies/tiles/).
