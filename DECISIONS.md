# Implementation decisions

Reviewed September 8, 2026 UTC (September 7 in Chicago).

1. **Local-first architecture.** The explicit Next.js/Fastify/Prisma/GitHub Pages brief takes precedence over a hosted Sites starter. No Sites project, GitHub remote or deployment was created. Next App Router exports one browser workspace route; stateful features call a separate authenticated API. SQLite retains key searchable columns plus validated canonical JSON for extensible specifications. `Observation` keeps source, ask, bid, availability and user-correction series separately.
2. **Supported versions and reproducibility.** Next 16.3.4, React 19.2.8, Fastify 5.12.3, Prisma 7.10.0, Tailwind 4.3.3, Zod 4.5.4 and the exact lockfile were verified. Prisma 7 was selected over the observed Prisma 8 release candidate. Supported Node 24 is the recommended install target. Patched `deepmerge-ts` and `mysql2` overrides remove the Prisma CLI dependency advisories; the resulting dependency audit reported zero vulnerabilities. Webpack is used for production builds because the environment’s Turbopack CSS subprocess could not bind its internal socket; development still uses Turbopack and has separate output.
3. **No fictional live inventory.** Research produced 1,576 actual ad observations from nine sources and 51 detail observations. Production smoke/enrichment runs followed. Source quantities are ads, not a verified count of available physical cars. Sample fixtures are isolated and excluded from production code/data. Known historical identifiers are preserved; only compatible modern complete formats or narrowly supported historical Mustang formats can support automatic grouping. Reviewed merge/unmerge keeps all original ad IDs and personal state.
4. **Travel uncertainty is a result.** The geocoder established Wheaton’s city center and bounded listing locations. No ORS credential was provided, so strict four-hour results remain zero. Vehicle-specific location evidence is required; generic dealer location is not automatically used. Lake Michigan tests explicitly reject close straight-line locations whose road route exceeds 240 minutes. Cached routes are non-traffic estimates, with option/endpoint keys and a freshness policy.
5. **Remote discovery differs from eligibility.** ClassicCars offered a 500-mile query but not a 300-mile query, so initial discovery rounded outward. Regional source inventory includes MI and IA candidates that may be too far by road. The editable envelope controls supported outward discovery; exact eligibility uses routes. Nationwide changes request URLs/jobs and records partial coverage. Public Autotrader refreshes changed to an unavailable-page response after initial success; this remains visible and is not worked around.
6. **Specialty expansion requires identity evidence.** Ford’s March 23, 2026 [2027 GTD announcement](https://www.fromtheroad.ford.com/us/en/articles/2026/mustang-gtd-applications-open-april-17) establishes the Mustang-family ceiling at 2027. Ordinary retail Mustang was 2026 at review. SVT/Cobra is initially selected, other variants explicit. A bare Cobra roadster is not a Mustang. Seller claims are reviewable; they are not upgraded by repetition. Explicit 1964½ Mustang wording can normalize to 1965 with wording retained; bare 1964 and impossible/conflicting years require review. Boundaries and VIN references are in `config/reference-facts.json` and `docs/REFERENCE_RESEARCH.md`.
7. **Conservative public export.** Original source pages, contact details, full identifiers and personal state remain local. Autotrader is omitted from public export until its redistribution terms are separately resolved. Photos link to the exact original ad and can disappear; no unrelated or generated car imagery substitutes for a listing. Manufacturer, source and geocoder references are dated; no appraisal or transaction value is inferred from asking prices.
8. **Simple bounded jobs.** Database leases, heartbeat renewal, run records, page/detail caps, per-origin delays and request bounds avoid Redis. Explicit failures never prove removal. Layout changes fail visibly. First alert evaluation is quiet. External delivery is opt-in and remains unverified; stable alert IDs support consumer deduplication after uncertain delivery.
9. **Personal data ownership.** Snapshot/sample state uses separate deployment-path keys; connected state uses the backend with optimistic revision checks. Manual imports merge and persist. Reviewed identity/location edits are separate user evidence and invalidate routes. Existing saved searches retain their defaults version. The public site cannot schedule private background work.
10. **Honest limitations.** This is a launchable initial product with substantial real discovery, not a complete market census. Most ad details are still pending. Specialty-marketplace breadth, current auction phase/bid feeds, actual ORS integration, external email/webhook delivery, and Windows and Docker execution are not independently verified. Both local websites were observed running simultaneously; shared-origin isolation was tested using both MuscleScout builds and a synthetic separate-app sentinel. No other project, browser credentials, cookies or seller account was accessed.


11. **Explicit handoff and supply-chain scope.** The documentation follow-up adds architecture, operations, implementation history and a prioritized unresolved-issues register rather than presenting catalog breadth as proven unique-car coverage. SBOMs use npm's installed dependency graph on the recorded macOS platform, supplemented by every lockfile entry and license. The optional WASM bundled-dependency limitation of lock-only export is retained explicitly. A dated advisory report and hashes accompany the inventory; no application license, exact unobserved bundled version or target-platform validation is invented.
